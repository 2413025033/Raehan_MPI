Tentang

Media pembelajaran ini dibuat untuk membantu memahami bagaimana alur kerja komputer dari Input → Proses → Output.

Materi disajikan secara sederhana dan visual agar mudah dipahami, sehingga pengguna dapat melihat bagaimana data masuk, diolah, hingga menghasilkan suatu output.

Selain materi, tersedia juga kuis interaktif untuk menguji pemahaman setelah mempelajari isi pembelajaran.
